# OBS 뉴스속보 규칙 기반 선별 (외부 AI API 사용 안 함)

## 운영 원칙

Cloudflare Worker → GitHub Actions → KBS/MBC/JTBC/연합뉴스 RSS → **고정된 규칙** → 암호화된 OBS 자막 → 중앙 기록 순서로 작동합니다.

Gemini 및 Groq 코드, API 호출, Actions 환경변수는 모두 제거했습니다. 외부 AI 사용료와 무료 API 429 할당량에 의존하지 않습니다.

## 단계별 필터

1. **출처 및 시간**: 등록된 언론사의 실제 기사 출처와 HTTPS 링크를 확인하고, 최근 90분 이내의 기사만 검토합니다. 국내 경계경보 발령·해제는 최근 15분 이내에 한합니다.
2. **절대 제외**: USGS 지진 자료, `[단독]`, 선관위·부정선거, 북한 미사일, 해외 뉴스, 저명하지 않은 지방기관 인사, 재탕·회고 기사.
3. **내용 확정 여부**: 정당 논평·주장·비난·촉구·관측·검토·방문·행사 등은 제외하고, 공식 사의·장관 임명 및 국회·정부·사법기관의 확정적 주요 결정 같은 *실제 사건*만 인정합니다. `[속보]` 표시만으로는 통과시키지 않습니다.
4. **중요도 점수**: 검증된 경계경보 100점, 핵심 국가인사 95점, 주요 법안·판결·의결 90점, 그 밖의 명확한 국가기관 중대 조치 80점. 기준 미달은 0점(제외). 한 번에 최대 3건을 우선 선정합니다.
5. **방송 문장**: 기사 원제목과 다른 안전한 요약이 가능할 때만 송출합니다. 원문을 그대로 자막에 표시하지 않습니다.
6. **중복·송출 속도**: 동일 사건은 24시간 이력으로 중복을 거르고, 자막은 30초간 표시하며 12분 간격 제한은 기존 OBS 로직을 유지합니다.
7. **기록**: 선정 기록, OBS 화면 표시 시작 기록을 구분하여 암호화 저장합니다. 과거 로그는 삭제하지 않습니다.

## 장점과 한계

API 키 발급이나 결제가 필요 없고, AI 무료 사용량 초과로 뉴스 심사가 멈추지 않습니다. 규칙과 우선순위가 고정되므로 결과를 재현할 수 있습니다.

다만 헤드라인만으로는 사건이 실제로 발생했는지 완전히 검증할 수 없고, 지나치게 엄격한 규칙이 중요한 뉴스를 놓칠 가능성도 있습니다. 이미 오래된 사건을 오늘 다시 보도한 기사의 실제 사건 시각을 완벽히 구별할 수도 없습니다.

## 수정하는 파일

- `runtime/config.json`: 최대 기사 수, 기사 유효기간, 명시적 제외 설정
- `runtime/collector.py`: 중요도 분류, 언론사 검증, 제목 재작성, 중복 검사
- `runtime/tests/test_rules_only.py`: 규칙 선별 회귀 테스트
- `runtime/web/view.js`: OBS에서 구형 항목을 최종 검증하는 안전장치

기존 Cloudflare Cron과 GitHub Pages URL, 비밀키 및 기록 저장 방식은 변경하지 않습니다.
